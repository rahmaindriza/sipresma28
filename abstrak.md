### ABSTRAK

Pengelolaan data akademik di SD Negeri 28 Kinali saat ini masih menggunakan Microsoft Excel secara terpisah pada masing-masing wali kelas. Hal ini mengakibatkan data tidak terintegrasi, risiko kehilangan data tinggi, lambatnya pengolahan nilai rapor, serta kesulitan Kepala Sekolah memantau prestasi siswa secara cepat. Penelitian ini bertujuan membangun Sistem Informasi Manajemen Nilai dan Monitoring Prestasi Siswa (SIPRESMA 28) berbasis web sebagai solusi pengolahan data terintegrasi.

Metode pengembangan sistem yang digunakan adalah *Waterfall*, dengan pemodelan diagram *Unified Modeling Language* (UML) dan *Entity Relationship Diagram* (ERD). Aplikasi ini dibangun menggunakan PHP dengan *framework* Laravel 11, Tailwind CSS, basis data MySQL, dan library Laravel-DomPDF untuk cetak laporan.

SIPRESMA 28 menyediakan hak akses bagi Administrator, Wali Kelas, Guru Mata Pelajaran, dan Kepala Sekolah. Fitur utama mencakup input nilai massal, kalkulasi nilai rapor otomatis, ranking kelas instan, penanda otomatis siswa di bawah KKM 75, dan monitoring grafik tren nilai. Hasil pengujian fungsionalitas menggunakan *Black Box Testing* dengan 22 skenario menunjukkan bahwa seluruh fitur sistem berjalan dengan baik dan sesuai rancangan.

**Kata Kunci**: *Sistem Informasi, Manajemen Nilai, Monitoring Prestasi, Laravel, Waterfall, Black Box Testing.*

### ABSTRACT

*Academic data management at SD Negeri 28 Kinali currently still uses separate Microsoft Excel spreadsheets by each homeroom teacher. This results in unintegrated data, high risk of data loss, slow report card processing, and difficulties for the Principal in quickly monitoring student achievements. This study aims to build a web-based Student Grade Management and Achievement Monitoring Information System (SIPRESMA 28) as an integrated data processing solution.*

*The system development method used is Waterfall, modeled with Unified Modeling Language (UML) and Entity Relationship Diagram (ERD). The application is built using PHP with Laravel 11 framework, Tailwind CSS, MySQL database, and Laravel-DomPDF library for report printing.*

*SIPRESMA 28 provides access rights for Administrator, Homeroom Teacher, Subject Teacher, and Principal. Key features include bulk grade inputs, automatic report card calculation, instant class ranking, automatic warnings for students scoring below the KKM threshold of 75, and grade trend graph monitoring. Functional testing using Black Box Testing with 22 scenarios shows that all system features operate successfully and according to design.*

***Keywords**: Information System, Grade Management, Achievement Monitoring, Laravel, Waterfall, Black Box Testing.*
